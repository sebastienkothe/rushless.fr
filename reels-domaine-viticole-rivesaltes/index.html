Domaines viticoles · Rivesaltes

Peut-on présenter Muscat de Rivesaltes et Rivesaltes dans le même reel ?

Oui si les références sont identifiées séparément et que vous validez les informations propres à chacune. Une sélection peut donner une vue de gamme. Pour raconter une élaboration ou une particularité précise, nous pouvons aussi concentrer le sujet sur une seule bouteille.

Une carte de dégustation suffit-elle pour commencer ?

Elle peut fournir les noms et les descriptions de vos références. Nous vérifions avec vous sa version actuelle et les visuels utilisables. Les sensations décrites à l’écran viennent de votre texte, sans ajouter une note de dégustation supposée à partir de la photo.

Peut-on préparer les contenus d’hiver avant les vendanges ?

Les sujets de gamme, d’étiquette ou d’accueil peuvent être préparés avec les éléments déjà disponibles. Les images de la nouvelle récolte s’ajouteront si vous souhaitez les intégrer. Aucun calendrier de salon ni rendez-vous de cave n’est annoncé sans confirmation de votre part.
